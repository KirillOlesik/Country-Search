# Дизайн и архитектура проекта "Country Search"

## 1. Отмена устаревших запросов (AbortController)

**Проблема:** При быстром вводе (например, `sp` -> `spain`), ответ на `sp` может прийти позже ответа на `spain` и перезаписать актуальные данные на экране устаревшими.
**Решение:** Использование `AbortController` для реальной отмены сетевого запроса. Отмена происходит при **каждом** изменении ввода (в методе `updateQuery`), а не только в момент срабатывания `debounce`.
**Почему не флаг:** Флаг "актуальности" просто игнорирует уже пришедший ответ, но сам запрос продолжает висеть в сети, потребляя трафик и занимая слоты соединений. `AbortController` физически разрывает соединение (статус `canceled` в Network).

## 2. Задержка debounce

Выбрана задержка в **300 мс**. Это оптимальный баланс: мы не отправляем запрос на каждое нажатие клавиши (экономим лимиты API), но как только пользователь перестает печатать, запрос уходит почти мгновенно, не создавая ощущения "тормозного" интерфейса.

## 3. Сложность (Big O) `mapCountryResponse`

Функция `mapCountryResponse` осуществляет маппинг одного объекта.
Временная сложность: **O(1)**, так как функция обрабатывает один объект фиксированной структуры. Внутренние методы `.map()` проходят по массивам языков и валют, которые крайне малы (обычно 1-3 элемента), поэтому этим можно пренебречь.
Пространственная сложность: **O(1)**.

## 4. Принципы чистого кода

1. **Single Responsibility Principle (SRP):** Каждый модуль отвечает за свое:
   - `debounce.ts` — задержка вызова.
   - `searchCountries.ts` — сетевой запрос и проверка HTTP-статусов.
   - `mapCountryResponse.ts` — преобразование данных.
   - `SearchController.ts` — оркестрация (управление отменой и вызов коллбэков).
   - `index.ts` — только отрисовка DOM.
2. **Чистые функции:** `mapCountryResponse` не мутирует входные данные (покрыто тестом).
3. **Безопасность (No innerHTML):** Весь интерфейс создается через `document.createElement`, что исключает XSS-атаки.
4. **Строгая типизация:** Никаких `any`. Используются интерфейсы `RawCountry` и `MappedCountry`, а для проверки ошибок в `catch` — Type Guards.
